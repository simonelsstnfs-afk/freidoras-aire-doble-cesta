# Guía y Comparativa Experta de Freidoras de Aire de Doble Cesta

Sitio web estático de afiliados de Amazon de alto rendimiento, optimizado para conversión (CRO) y motores de búsqueda con IA (AEO/GEO).

## Características Técnicas
- **Arquitectura:** HTML5 semántico, CSS3 modular puro sin dependencias pesadas, Vanilla JavaScript.
- **Componentes:** Motor interactivo side-by-side de comparación, radar charts 0-10 vectoriales para evaluación técnica.
- **Rendimiento:** 100% de imágenes de producto locales en alta resolución en `assets/img/`.
- **AEO / GEO:** Marcado estructurado Schema.org JSON-LD (`Product`, `Offer`, `AggregateRating`, `Review`, `FAQPage`, `BreadcrumbList`).
- **Despliegue:** Optimizado para Vercel (`vercel.json`) y Hostinger (`.htaccess`).
